# Fiches biographiques du convoi des 31000

Site statique prêt pour GitHub Pages. La page d’accueil `index.html` répertorie 102 fiches biographiques et permet une recherche par nom ou matricule.

## Publication sur GitHub Pages

1. Créer un nouveau dépôt GitHub.
2. Déposer tous les fichiers de ce dossier à la racine du dépôt.
3. Dans **Settings → Pages**, sélectionner **Deploy from a branch**.
4. Choisir la branche **main** et le dossier **/(root)**, puis enregistrer.

Le fichier `.nojekyll` indique à GitHub de publier directement les fichiers HTML sans traitement Jekyll.
