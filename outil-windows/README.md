# Mémoire Portraits — logiciel Windows

Ce logiciel crée et publie une nouvelle fiche sur `memoiredesdeportes.fr` sans intelligence artificielle.

## Utilisation

1. Ouvrir `MemoirePortraits.exe`. Le formulaire s’ouvre dans votre navigateur et reste uniquement sur votre ordinateur.
2. Vérifier le dossier du site proposé.
3. Saisir le nom, le matricule, la biographie et l’URL de la source.
4. Choisir une photographie si elle est disponible et indiquer obligatoirement son crédit.
5. Cliquer sur **Créer et publier sur GitHub**.
6. Vérifier le récapitulatif avant de confirmer.
7. Cliquer sur **Fermer le logiciel** lorsque le travail est terminé.

Le matricule classe automatiquement la fiche :

- `31xxx` : femmes du convoi des 31 000 ;
- `45xxx` ou `46xxx` : hommes du convoi des 45 000.

Le logiciel ne rédige pas la biographie et n’invente aucune information. Il publie exactement le texte fourni. Une connexion Internet, Git et l’accès déjà configuré au dépôt GitHub sont nécessaires pour publier.
