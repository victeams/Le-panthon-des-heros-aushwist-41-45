# Mémoire Portraits — logiciel Windows

Ce logiciel crée et publie une nouvelle fiche sur `memoiredesdeportes.fr` sans intelligence artificielle.

## Utilisation

1. Ouvrir `MemoirePortraits.exe`. Le formulaire s’ouvre dans votre navigateur et reste uniquement sur votre ordinateur.
2. Vérifier le dossier du site proposé.
3. Choisir **Texte complet déjà rédigé** ou **Rédaction guidée dans le style du mémorial**.
4. En mode guidé, renseigner au moins trois parties : origines, engagement, arrestation, déportation, retour ou décès, mémoire.
5. Saisir l’URL exacte de la source.
6. Choisir une photographie si elle est disponible et indiquer obligatoirement son crédit.
7. Cliquer sur **Créer et publier sur GitHub**.
8. Vérifier le récapitulatif avant de confirmer.
9. Cliquer sur **Fermer le logiciel** lorsque le travail est terminé.

Le matricule classe automatiquement la fiche :

- `31xxx` : femmes du convoi des 31 000 ;
- `45xxx` ou `46xxx` : hommes du convoi des 45 000.

Le logiciel n’invente aucune information. Le mode guidé assemble vos paragraphes dans l’ordre chronologique du mémorial, sans modifier les faits fournis. Une connexion Internet, Git et l’accès déjà configuré au dépôt GitHub sont nécessaires pour publier.
